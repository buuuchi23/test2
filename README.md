# 🌱 育休中意識高めよう委員会

自分で作った「やりたいことリスト」から今日やることを選んで、毎日の達成を記録するアプリです。
iPhone・iPad のホーム画面に追加して使います。データはその端末の中だけに保存され、外には送られません。

- アプリのURL：**https://buuuchi23.github.io/test2/**
- 機内モードでも使えます（最初の1回だけインターネットにつながった状態で開いてください）

---

## 1. GitHub アカウントの作成から GitHub Pages で公開するまで

> いまのアプリはすでに公開済みです。新しく別のアカウントやリポジトリで公開し直すときの手順です。

### 1-1. GitHub アカウントを作る
1. ブラウザで https://github.com を開き、「**Sign up**」を押します。
2. メールアドレス・パスワード・ユーザー名（英数字）を入れて進みます。
   ユーザー名はアプリのURL（`https://ユーザー名.github.io/...`）に使われます。
3. メールに届いた確認コードを入力すると、アカウントができあがります。

### 1-2. リポジトリ（ファイルを置く場所）を作る
1. ログインした状態で、右上の「**＋**」→「**New repository**」を押します。
2. 「Repository name」に名前を入れます（例：`ikukyu-app`）。これもURLの一部になります。
3. 「**Public**」を選びます。
   ※無料プランでは Public でないと GitHub Pages で公開できません。公開されるのはアプリのプログラムだけで、あなたが入力したデータは公開されません。
4. 「**Create repository**」を押します。

### 1-3. アプリのファイルをアップロードする（パソコンがおすすめ）
1. 作ったリポジトリの画面で「**uploading an existing file**」（または「Add file」→「Upload files」）を押します。
2. アプリのファイル一式（`index.html`、`style.css`、`sw.js`、`manifest.webmanifest`、`js` フォルダ、`icons` フォルダ）を、画面にまとめてドラッグ＆ドロップします。
   フォルダごとドラッグすれば中身もそのまま入ります。
3. 下の「**Commit changes**」を押します。

### 1-4. GitHub Pages をオンにする
1. リポジトリの「**Settings**」→ 左側の「**Pages**」を開きます。
   （スマホで Settings が見つからないときは `https://github.com/ユーザー名/リポジトリ名/settings/pages` を直接開きます）
2. 「Build and deployment」の **Source** を「**Deploy from a branch**」にします。
3. **Branch** で「**main**」と「**/ (root)**」を選び、「**Save**」を押します。
4. 1〜3分待ってページを再読み込みし、「**Your site is live at …**」と出たら公開完了です。
   URL は `https://ユーザー名.github.io/リポジトリ名/` です。

> いまのアプリ（buuuchi23/test2）は、`claude/ikukyu-pwa-app-mwmof7` というブランチから公開しています。

## 2. iPhone・iPad の Safari でホーム画面に追加する方法

1. **Safari** でアプリのURL（https://buuuchi23.github.io/test2/ ）を開きます。
2. 共有ボタン（四角から上向きの矢印 ⬆️）を押します。
   - iPhone：画面のいちばん下（または「…」メニューの中）
   - iPad：画面右上、アドレスバーの横
3. メニューを下にスクロールして「**ホーム画面に追加**」を押します。
4. 名前（「意識高め委員会」）を確認して、右上の「**追加**」を押します。
5. ホーム画面に 🌱 のアイコンができます。**これからはこのアイコンから開いて**ください。

### 気をつけること
- **Safari で開いたときと、ホーム画面のアイコンから開いたときでは、データが別々に保存されます。**
  Safari で入力したデータをアイコン側に移したいときは、「4. データを移す方法」と同じやり方（Safari 側でエクスポート → アイコン側でインポート）で移せます。
- アイコンを長押しして「ブックマークを削除」すると、**そのアプリのデータも消えます**。消す前に必ずエクスポートしてください。

## 3. アプリを修正したときの更新方法

### 3-1. 修正を反映させる
- **Claude Code に頼む場合**：修正をお願いすると、Claude Code が GitHub に反映（プッシュ）します。1〜3分で公開中のアプリに反映されます。
- **GitHub の画面で自分で直す場合**：
  1. 直したいファイルを開いて、右上の ✏️（鉛筆）を押して編集し、「**Commit changes**」を押します。
  2. **`sw.js` の3行目 `const VERSION = 'v11';` の数字を1つ上げて**（例：`v11` → `v12`）、同じように保存します。
     これを忘れると、iPhone・iPad に古い画面が残ったままになります。
  3. 新しいファイルを追加したときは、`sw.js` の `FILES` の一覧にもそのファイル名を書き足します。
- 反映が終わったかどうかは、リポジトリの「**Actions**」タブで「pages build and deployment」に緑のチェックが付いていれば完了です。

### 3-2. iPhone・iPad で新しいバージョンにする
1. ホーム画面のアイコンからアプリを開きます（インターネットにつながった状態で）。
2. 画面の上に「**新しいバージョンがあります［更新する］**」が出たら「**更新する**」を押します。
3. 「設定」画面のいちばん下の「バージョン」が新しい数字になっていれば完了です。データはそのまま残ります。

### 3-3. 古い画面が残るとき
上から順に試してください。
1. 1〜3分待ってから、もう一度アプリを開き直す（反映に少し時間がかかることがあります）。
2. アプリを**完全に閉じて**から開き直す。
   画面の下から上へスワイプして止めるとアプリの一覧が出るので、このアプリを上にはじいて閉じます。これを2回ほどくり返すと「更新する」が出ることが多いです。
3. それでもだめなときの最後の手段（**データが消えるので、必ず先にエクスポート**してください）：
   1. 設定 →「📤 エクスポート」でデータを保存する
   2. ホーム画面のアイコンを長押し →「ブックマークを削除」
   3. Safari でURLを開き直して、もう一度ホーム画面に追加する
   4. 新しいアイコンから開き、設定 →「📥 インポート」で保存したファイルを読み込む

## 4. iPhone と iPad の間でデータを移す方法

iPhone と iPad のデータは自動ではつながりません。ファイルを使って手で移します。

### 移す元の端末（例：iPhone）
1. アプリの「**設定**」→「**📤 エクスポート（書き出す）**」を押します。
2. 共有メニューが出るので、どちらかを選びます。
   - **AirDrop**：移す先の iPad を選ぶ（近くにあって、AirDrop を受け取れる状態にしておきます）
   - **“ファイル”に保存**：「iCloud Drive」を選んで「保存」（同じ Apple ID の iPad から見られます）

### 移す先の端末（例：iPad）
1. アプリの「**設定**」→「**📥 インポート（読み込む）**」を押します。
2. ファイルを選ぶ画面で、さっきのファイル（`ikukyu-backup-日付.json`）を選びます。
   - AirDrop で受け取ったファイルは「ファイル」アプリの「**ダウンロード**」フォルダに入っています。
   - iCloud Drive に保存した場合は「**ブラウズ**」→「**iCloud Drive**」の中にあります。
3. 件数を確認する画面が出るので、「**読み込む**」を押します。

### 気をつけること
- インポートすると、**移す先の端末のデータはすべて消えて**、ファイルの内容に置き換わります（足し合わせではありません）。
- 両方の端末で別々に入力すると、どちらかの入力が消えてしまいます。**ふだん使う端末を1つに決めて**、移すときだけ使うのがおすすめです。
- もしものときのために、ときどきエクスポートして iCloud Drive に保存しておくと安心です（設定画面に「最後に書き出した日時」が表示されます）。
